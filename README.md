# 云岭民族文化数字图谱

云南民族文化资源的纯静态数字展览，包含地图漫游、民族索引、山水故事、纹样档案、WebGL 三维展厅、拼纹工坊与本地收藏。

## 发布与更新

本仓库通过 GitHub Pages 和 GitHub Actions 自动发布。向 `main` 分支推送后，工作流会重新部署仓库根目录中的静态文件；也可在 GitHub Actions 页面手动运行部署工作流。

所有界面交互在浏览器本地完成。地图边界、插画、纹样均随站点提供。

## 内容来源与说明

民族名录参考云南省民族宗教事务委员会公开资料；红河哈尼梯田专题参考 UNESCO World Heritage Centre；行政区边界数据来自阿里云 DataV GeoAtlas。站内 10 张概念插画为 AI 生成，50 枚 SVG 为原创形态练习，WebGL 场景为程序化创作；它们不替代实地采集、社区授权、讲述者校核或精确测绘。

- 民族名录：https://mzzj.yn.gov.cn/html/2021/liuyangongkai_0202/38569.html
- UNESCO：https://whc.unesco.org/en/list/1111/
- 行政区边界：https://geo.datav.aliyun.com/areas_v3/bound/530000_full.json
